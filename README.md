# Oktan Auto

Desktop Car Service Management App
##A desktop application designed to manage car service workflows. It allows users to track customers currently in the shop, handle check-ins and removals, and select specific service types with automated price calculation. To finalize a service, all required options must be selected and the necessary data entered. Once completed, the customer’s status is updated to "Finished."
##Tech Stack:
  *Frontend: HTML, CSS, React
  *Notifications: React-hot-toast (used for real-time feedback during add, delete, and completion actions)

//
Moja desktop verzija aplikacije auto servisa koja ucitava listu korisnika koji su u servisu, takodje kontrolise njihovo dodavanje ili brisanje, i vrsi odabir vrste servisa koji zelimo da uradimo i na osnovu njega kalkulise cenu servisa. Da bi zavrsili servis potrebno je selektovati sve opcije u servisu i ukucati potrebne podatke. Klikom na dugme zavrsi korisnik prelazi u stanje "zavrsen."

Aplikacija je izradjena upotrebom HTML, CSS, React i React-hot-toast biblioteke za implementaciju notifikacija prilikom dodavanja, brisanja i zavrsetka servisa.
